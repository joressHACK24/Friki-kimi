## 🚀 MVP v0.1: Fritz Compliance Scanner
**Upload → Analyse → Report. Made in Germany.**

### Was ist FKI?
FKI ist keine allgemeine KI. Fritz versteht den deutschen Mittelstand:
- DSGVO-Erklärungen prüfen
- Verträge auf Risiken scannen
- Compliance-Reports generieren
- Alles auf Deutsch, mit deutschem Rechtsverständnis
